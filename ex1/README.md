# Example 1

## About 

Uses the `ws` package to create a very simple WebSocket server/client connection over port 8080.

## How to Run Locally

1. in one terminal window, type ~~`node server`~~ `node example1-server`
2. in another terminal window, type ~~`node client`~~ `node example1-client` 

(Use `node <name of file to serve>`)
