# Example 2

## About 

- Integrates with the sister repo `pywebsocket3` from [GoogleChromeLabs](https://github.com/GoogleChromeLabs/pywebsocket3.git).
- Uses the `websocket` package 

## How to Run Locally

1. start the standalone websocket server (pywebsocket3), which is cloned in a neighboring directory
2. open the index.html file and click "Run WebSocket" link
