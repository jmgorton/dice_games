# Architecture Diagram & Flow

## System Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                     CLIENT (Browser/App)                        │
│                                                                 │
│  1. Call login()                                                │
│  2. POST /auth/login with password                              │
│  3. Store token in localStorage                                 │
│  4. Include token in all subsequent requests                    │
└────────────────┬────────────────────────────────────────────────┘
                 │
                 │ HTTP/1.1
                 │
         ┌───────▼────────────────────────────────┐
         │  NGINX (Port 8080)                     │
         │  Load Balancer / Reverse Proxy         │
         ├────────────────────────────────────────┤
         │ Routes:                                │
         │  /auth  ──> main-auth-1:6502        │
         │  /play  ──> main-play-1:9090        │
         │  /      ──> main-app-1:3000         │
         └────┬─────────────────┬────────────────┘
              │                 │
              │                 │
       ┌──────▼──────┐   ┌──────▼──────┐
       │ AUTH        │   │ PLAY        │
       │ Service     │   │ Service     │
       │ :6502       │   │ :9090       │
       ├─────────────┤   ├─────────────┤
       │ Routes:     │   │ Routes:     │
       │ POST /login │   │ GET /play   │
       │ POST /logout│   │ WS /play    │
       │ GET /health │   │             │
       └──────┬──────┘   └──────┬──────┘
              │                 │
              │                 │
         ┌────▼─────────────────▼────┐
         │ shared/                    │
         │ ├─ token-store.js          │
         │ └─ client-auth.js          │
         └────────────────────────────┘
```

## Request Flow Diagram

### Successful Authentication Flow

```
Client                Auth Service              Play Service
  │                        │                         │
  ├─ POST /auth/login ────>│                         │
  │  {"password":"..."}    │                         │
  │                        ├─ validate password      │
  │                        ├─ create token          │
  │<─ {"token":"xyz..."} ──┤                         │
  │                        │                         │
  │                                                  │
  ├─ GET /play ──────────────────────────────────>│
  │  {Authorization: Bearer xyz...}                 │
  │                              ├─ authenticator()  │
  │                              ├─ validateToken()  │
  │                              ├─ success!        │
  │<───────── 200 OK ────────────────────────────┤
  │  (or WebSocket upgrade)                        │
  │                                                  │
```

### Failed Authentication Flow

```
Client                Auth Service              Play Service
  │                                                  │
  ├─ GET /play ──────────────────────────────────>│
  │  (no Authorization header)                     │
  │                              ├─ authenticator()  │
  │                              ├─ validateToken()  │
  │                              ├─ FAIL!           │
  │                              ├─ errorHandler()  │
  │<──────── 500 Unauthorized ────────────────────┤
  │                                                  │
```

## Token Lifecycle

```
┌─────────┐
│ Created │  Token generated by auth service
│ (login) │  → token_<timestamp>_<random>
└────┬────┘
     │
     ▼
┌─────────┐
│ Valid   │  Token accepted for requests
│ (use)   │  → each request updates lastActivity
└────┬────┘
     │
     ▼
┌─────────┐
│ Revoked │  Token deleted from store
│ (logout)│  → subsequent requests rejected
└─────────┘

FUTURE:
┌─────────┐
│ Expired │  Token automatically invalidated
│ (TTL)   │  → would need background cleanup job
└─────────┘
```

```

## Middleware Pipeline (Play Service)

```
HTTP Request arrives
    │
    ▼
┌─────────────────┐
│  Logger         │  Logs: [timestamp] METHOD URL from Origin
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Validator      │  Validates request format, origin
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Authenticator  │  ◄── OUR NEW AUTH LOGIC HERE
│                 │  
│  1. Extract token from:
│     - Authorization header
│     - x-auth-token header
│     - ?token query param
│  2. Validate token against store
│  3. Update lastActivity
│  4. Attach token to request
└────────┬────────┘
         │
         ▼
   [Pass/Fail]
         │
    ┌────┴────┐
    │          │
    ▼          ▼
 Error    Route Handler
Handler   (serveStaticFile,
(500)     getHostname, etc.)
          ▼
       Response
```

Map<string, object>
{
  "token_1705598400123_abc123def456": {
    createdAt: 2024-01-18T15:30:45.123Z,
    lastActivity: 2024-01-18T15:30:52.456Z
  },
  "token_1705598401234_def456ghi789": {
    createdAt: 2024-01-18T15:30:46.234Z,
    lastActivity: 2024-01-18T15:30:47.890Z
  }
  // ... more tokens
}

Note: Keys are unique tokens
      Values track session metadata
      O(1) lookup performance
```
